RumahKas — situs anggaran rumah tangga berbahasa Indonesia untuk Keluarga Prasetyo: dasbor bulanan dengan diagram pengeluaran per kategori, daftar transaksi yang bisa ditambah/diubah/dihapus lengkap dengan saldo berjalan, anggaran tiap kategori dengan peringatan lewat batas, target tabungan dengan setoran, dan laporan tren 6 bulan beserta kesimpulan yang dihitung dari data. Semua data tersimpan di localStorage peramban; tidak ada permintaan jaringan.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080. Atau sajikan folder `app/` dengan server statis apa pun (mis. `python3 -m http.server -d app`).
